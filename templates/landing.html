Security

Built for trust

Production-grade security baked in at every layer, not bolted on after.

Secure WebSocket Communication

Every WebSocket connection is authenticated via short-lived JWT tokens before a room channel is joined. Messages are validated server-side and access control ensures only room members can send or receive events.

Token-based auth Message validation Access control

Safe Media Handling

Uploads are gated behind DRF-authenticated endpoints with strict file-type allowlists and a hard 10 MB size limit. Files are stored on Cloudinary — never on the application server.

File type validation Size limits DRF upload endpoints
